# Adaptable review report outline

Use only sections useful for the requested scope. Tables, prose and a concise chat response can all satisfy the task. This is not a required schema.

1. Main findings and recommended next actions, ordered by importance.
2. For each issue: what differs, why it matters, tender requirement and bid evidence locations, uncertainty and feasible correction/question.
3. Independent review decisions: retained, withdrawn, revised or follow-up, with reasons.
4. Actual reviewed materials/scope and unresolved or unreadable areas with impact.
5. Changed inputs or unresolved disagreements relevant to follow-up.

Avoid invented coverage percentages, unsupported rejection verdicts and an overall “complete” label when important review work remains unfinished. A requested legacy JSON export is a separate deliverable.
