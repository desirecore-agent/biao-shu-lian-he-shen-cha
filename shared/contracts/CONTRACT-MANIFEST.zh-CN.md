# 可选导出资源清单 — v1.2

以下资源保持原状，仅支持明确要求的旧导出，与 0.2.0 成果导向团队说明区分。

| 资源 | 可选导出用途 |
| --- | --- |
| schemas/project-profile.schema.json | 项目背景 |
| schemas/file-manifest.schema.json | 原件清单和版本 |
| schemas/requirements.schema.json | 要求引用 |
| schemas/coverage.schema.json | 已查、失败与未查范围 |
| schemas/findings.schema.json | 发现及依据 |
| schemas/review-report.schema.json | 导出总结与未决项 |

六份均为 Draft-07 和 v1.2 标识。保留的 Evidence 校验器要求该六类导出及内部版本、覆盖一致性。这些要求不适用于普通自然语言报告，此处不声称新的冻结哈希或验证成绩。

可选执行见 [README](README.zh-CN.md) 和 Evidence 技能依赖文档。安装来源及身份锁属于发布元数据，不是业务任务准备。
