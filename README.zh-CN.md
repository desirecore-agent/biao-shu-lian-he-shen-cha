# 标书联合审查

由总审、条款、商务、视觉及独立证据复核五个角色组成。0.2.0 使用清晰自然语言任务与成果质量标准，成员自主选择方法及有效交付形式。

从[使用指南](USAGE.zh-CN.md)开始。[项目说明](PROJECT.zh-CN.md)、[共享规则](shared/rules.md)和[质量量表](shared/quality-rubric.zh-CN.md)说明职责、好坏示例及定向补充方法。

审查发现应重要、有依据、可定位、可行动，不可读材料和未完成工作要明确。普通复核不要求固定输入输出 Schema 或六文件包，[旧契约](shared/contracts/README.zh-CN.md)仅供可选导出。

通过市场发布版本安装并审阅团队规则。来源锁保护安装身份，不证明业务准确率。现有测试记录使用合成材料。所选模型可能处理文档图片，额外服务传输需授权。团队辅助人类审查，不鉴真、不保证中标。
